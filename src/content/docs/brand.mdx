Jaci is an independent open-source fork of Luau optimized for general-purpose programming, standalone applications, and native embedding.

## Referring to Jaci

You are welcome to refer to Jaci when building tools, libraries, or applications for the language.

When referring to the project:
* **Jaci** is the official name of the independent language project and runtime.
* The standard CLI tools and compiler binaries remain named `luau` and `luau-analyze` for standard compatibility and tooling consistency.
